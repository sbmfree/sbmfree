CantayaOS

My main project is CantayaOS, an experimental operating system I’m developing from scratch for AArch64.

The project currently includes:

* Rust-based UEFI bootloader
* Custom AArch64 kernel
* EL0 user processes
* Virtual memory and isolated process address spaces
* Timer-based preemption
* System calls
* Process and thread management
* Handle-based kernel objects
* VirtIO-backed FAT filesystem access
* ELF executable loading
* Kernel I/O management
* QEMU virt + AArch64 OVMF development environment

My long-term goal with CantayaOS is to continue exploring modern operating-system architecture while building increasingly capable kernel, user-space and eventually graphical components.
